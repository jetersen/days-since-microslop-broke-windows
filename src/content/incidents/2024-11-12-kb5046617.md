The November 12, 2024 cumulative update KB5046617 for Windows 11 24H2 had severe installation issues. Users reported the update getting stuck during installation at various points (6%, 35-40% completion) with error codes 0x80070003, 0x800f0922, and 0x800f0991. Microsoft confirmed that when installed via installation media (USB or CD), KB5046617 blocks the installation of all future security updates and patches. The issue did not occur when installation was done via Windows Update or the Microsoft Update Catalog. The problem was ultimately resolved on December 10, 2024, when the December 2024 monthly security update was released—users needed to ensure installation media included this December update or later to avoid the blocking issue.
