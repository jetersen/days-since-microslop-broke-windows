June 2026's Patch Tuesday — the update patching a record-setting batch of security flaws — broke machines on the way in. The worst reports came from HP business PCs (EliteBook, ProBook, ZBook, and even Engage One Pro point-of-sale systems): after installing KB5094126, machines rebooted into recovery mode, threw 0xc0430001 BSODs, blank blue screens, Secure Boot verification errors, or demanded BitLocker recovery keys. The update touches Secure Boot files, certificates, and Boot Manager, and on devices imaged with older 100 MB EFI partitions, Windows simply failed to write what it needed. On domain-joined enterprise machines, OneDrive integration in File Explorer went dead — the sidebar icon remained, but clicking it did nothing. The Recycle Bin started showing internal file names in delete-confirmation dialogs instead of the actual file being deleted, a bug Microsoft confirmed on every supported Windows client and server release. Third-party applications using OLE automation lost the ability to launch Office apps or open documents. And for good measure, the update failed to install on some machines with 0x800F0823 and 0x800f0922 errors. The Recycle Bin bug was fixed in the June 23 preview update and again in July's Patch Tuesday, which also fixed OneDrive shortcuts breaking when File Explorer runs elevated. The HP boot failures never got a confirmed fix, and similar Secure Boot verification errors, black screens and BitLocker prompts kept showing up on HP hardware after the July update too.
