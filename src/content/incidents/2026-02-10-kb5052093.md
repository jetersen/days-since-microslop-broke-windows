The February 2026 update broke Windows Search yet again. Searching from the Start Menu or taskbar returns zero results for locally installed applications, files, and settings. The search indexer service consumes excessive CPU while simultaneously finding nothing. Users are directed to use File Explorer to navigate to their programs manually, like it's 1998. At least Bing web results still show up in the Start Menu — priorities.
