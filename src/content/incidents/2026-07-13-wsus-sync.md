For once there was no KB to blame: a buildup of publishing metadata, both on existing WSUS installations and on Microsoft's service side, left Windows Server Update Services synchronisation crawling or timing out outright. Impact ramped up from July 13, 2026 — Patch Tuesday week, naturally, when organisations most needed their update servers working — and Microsoft opened the issue on July 17. A service-side mitigation deployed on July 18 restored normal sync times for new and rebuilt WSUS servers, but administrators sitting on existing installations had to manually clean out the accumulated metadata themselves, following the steps in KB5121986. Affected platforms spanned essentially every supported Windows client and server release back to Windows Server 2012.
